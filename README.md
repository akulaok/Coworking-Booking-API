# Coworking-Booking-API

REST API для бронирования рабочих мест и переговорных комнат в коворкинге.

## Документация и тестирование

- [Swagger UI](https://akulaok.github.io/Coworking-Booking-API/) — описание API и интерактивное выполнение запросов.
- [Mockzilla](https://quiet-lynx-29.api.mockz.io/#/services/openapi?ix=5) — mock-сервер для тестирования эндпоинтов и просмотра ответов.

## Реализованные эндпоинты

- Просмотр и управление ресурсами коворкинга.
- Создание, просмотр и отмена бронирований.
- Просмотр всех бронирований администратором.
